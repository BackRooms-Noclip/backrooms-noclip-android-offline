# Contribuir

1. Crea una rama desde `main`.
2. Ejecuta las pruebas indicadas en `README.md`.
3. Abre un Pull Request describiendo los cambios jugables.
4. No elimines `LICENSE.md` ni `NOTICE.md`.
5. No introduzcas servidores, telemetría ni dependencias de red sin aprobación explícita del proyecto.

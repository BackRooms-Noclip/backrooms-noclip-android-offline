# Manual de la edición Android offline

La aplicación funciona completamente en el dispositivo. No requiere cuentas, servidor ni conexión.

- Crea o selecciona un perfil en la portada.
- Pulsa **INICIAR EXPEDICIÓN**.
- El progreso se almacena localmente mediante el almacenamiento de la WebView.
- Usa el menú del juego para ajustar gráficos, controles, sonido y mando.

Controles principales: W/A/S/D o controles táctiles para moverte, Espacio para interactuar, Q/E para usar las manos, F para linterna, B para mochila, M para mapa, C para Códice y ESC para ajustes.
